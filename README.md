# HTML Básico

## Tags utilizadas

### <!DOCTYPE html>
Informa ao navegador que o documento utiliza a versão HTML5.

### <html>
É o elemento raiz da página HTML.

### <head>
Contém informações sobre a página, como título e configurações.

### <meta>
Define configurações como a codificação de caracteres e a responsividade.

### <title>
Define o título exibido na aba do navegador.

### <body>
Contém todo o conteúdo visível da página.

### <h1>
Representa o título principal da página.

### <h2>
Representa subtítulos ou seções da página.

### <p>
Cria um parágrafo de texto.

### <ul>
Cria uma lista não ordenada (com marcadores).

### <ol>
Cria uma lista ordenada (numerada).

### <li>
Representa um item dentro de uma lista.
